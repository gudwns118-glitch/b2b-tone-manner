# b2b-tone-manner

AI가 쓰는 업무 글의 번역투·과장 수사 대신, 본인이 실제로 쓰는 문체를 Claude에 일괄 적용하는 Claude Code 플러그인입니다. 한 스킬 안에 **메일 모드**와 **문서 모드**가 있고, 요청 내용을 보고 알아서 모드를 고릅니다. 회사가 바뀌어도 그대로 쓰도록 문체 규칙과 회사별 값을 분리했습니다. 레포에는 문체 규칙만 있고, 이름·회사 정보는 설치한 사람의 PC에만 저장됩니다.

## 무엇으로 만들었나

| 모드 | 근거 |
|---|---|
| 메일 | 직접 보낸 1:1 업무 메일 **926통**. 2025-11~2026-10에 480통, 2025-03~10과 2026-11에 446통입니다. 여기에 콜드메일 템플릿 16종을 더했습니다. 대량·자동 발송은 제외했고, 중복을 제거한 뒤 스레드당 15통으로 제한했습니다. |
| 문서 | 직접 쓴 Notion·Google Docs·Slides **30건**(2022~2026)과 고객 제안 장표 2건. 포트폴리오·회고, 회의자료·협의안, 기획안, 보고·타운홀 슬라이드, 협조 공문, 상세페이지를 포함합니다. AI 보조 흔적이 강한 문서는 대조군으로만 썼습니다. |

- 표현 빈도·종결 방식·기호·이모지·길이를 정량으로 집계했고, 규칙마다 근거 수치를 적었습니다.
- 메일 두 표본(480통, 446통)에서 주요 수치가 거의 같았습니다. 예를 들어 "편하게"는 70.0%와 69.1%, "~주신"은 48.1%와 47.8%였습니다. 그래서 이 규칙은 시기가 바뀌어도 유지되는 말투로 봅니다.
- 모든 예문은 익명화했고, 사람·회사·금액 자리는 `{ }`로 표시했습니다.

## 구성

```
.claude-plugin/              플러그인·마켓플레이스 매니페스트
hooks/                       메일·문서 요청에 스킬을 강제로 거는 UserPromptSubmit 훅 (플러그인 설치 시 자동 등록)
skills/b2b-tone-manner/
  SKILL.md                   진입점. 회사 인식 → 모드 판정 → 공통 원칙 → 절차
  email/                     메일 모드
    voice.md                 뼈대, 문장, 어휘, 띄어쓰기, 기호·이모지, 수신자별 차이, 제목
    anti-patterns.md         AI 번역투 대조표, Before/After, 자기검수 체크리스트
    situations.md            상황 14종의 뼈대와 예문
    cold-outreach.md         콜드메일 제목 공식·흐름·CTA
  document/                  문서 모드
    voice.md                 매체별 종결, 주어, 연결어, 숫자·근거, 기호·서식, 어휘
    types.md                 포트폴리오·회의자료·기획안·슬라이드·보고·작업 요청·협조 공문·B2C 카피 뼈대
    anti-patterns.md         AI 문서 문체 대조표, 자기검수 체크리스트
  companies/_template/       회사 profile 빈 양식 (실제 값은 아래 사용자 폴더에)
  update/                    문체 갱신
    UPDATE.md                최근 메일·문서로 규칙을 다시 재는 절차
    extract.py, analyze.py   Gmail 결과에서 본인 메일 추출(html 본문 포함), 표현 빈도 집계
    analyze_docs.py          문서 문장 종결 비율 집계
```

사용자별 값은 레포가 아니라 각자의 PC에 생깁니다. 플러그인을 업데이트해도 지워지지 않습니다.

```
~/.claude/b2b-tone-manner/
  me.md                      이름·영문 이름 (처음 쓸 때 한 번 물어 저장)
  companies/<회사>/profile.md  회사명·메일 도메인·팀·서명·업무 어휘·회사 규칙 (모드 규칙보다 우선)
```

## 설치

Claude Code 세션 안에서 실행합니다.

```
/plugin marketplace add gudwns118-glitch/b2b-tone-manner
/plugin install b2b-tone-manner@b2b-tone-manner
```

설치하면 스킬과 자동 적용 훅이 함께 등록되고, 새 세션부터 적용됩니다.

처음 메일이나 문서를 부탁하면 Claude가 이름을 한 번 묻고, 업무 메일 도메인을 보고 "회사 프로필을 만들까요?"라고 묻습니다. 승인하면 회사명·팀·직급·서명 관례만 답하면 됩니다. 그 전에도 문체 규칙은 바로 적용됩니다.

- 업데이트: `/plugin marketplace update b2b-tone-manner` → `/plugin update b2b-tone-manner`
- 제거: `/plugin uninstall b2b-tone-manner`
- 훅은 Node.js가 필요합니다. 트리거 단어는 `hooks/tone-trigger.mjs`의 `TRIGGER` 정규식에서 고칩니다.
- 이전 방식(`~/.claude/skills`에 클론하고 `settings.json`에 훅 수동 등록)을 썼다면 그 훅 항목은 지웁니다. 남겨 두면 플러그인 훅과 두 번 실행됩니다.
- Claude.ai에서 쓸 때는 `skills/b2b-tone-manner` 폴더를 zip으로 묶어 Settings → Capabilities → Skills에 업로드합니다. 훅은 Claude Code 전용입니다.

## 사용

스킬 이름을 부를 필요는 없습니다. 아래처럼 말하면 모드를 골라 적용합니다.

- 문서: "○○기관 제안서 장표 초안 써줘. 할인율 30%, 1,500명, 12개월"
- 메일: "○○사에 견적서 보내는 메일 써줘. 23명, 3개월, 기존 단가 동일"
- 메일 교정: "이 메일 내 말투로 고쳐줘" + AI가 쓴 초안
- 문서: "이번 제휴 프로젝트 노션 회고로 정리해줘" + 메모
- 문서: "○○사 협의용 회의자료 초안 만들어줘. 결정할 건 오픈 일정이랑 권한 범위"
- 문서 교정: "이 기획안 AI 티 빼줘"

## 이직했을 때

1. `~/.claude/b2b-tone-manner/companies/<이전 회사>/profile.md`의 `period`에 끝 날짜를 적습니다(`2025-03 ~ 2027-01`). 새 회사 메일 도메인이 등록된 회사와 다르면 Claude가 "새 회사 프로필을 만들까요?"라고 묻습니다. 승인하면 양식을 복사해 회사명·팀·직급·서명만 채웁니다. 그동안은 모드 규칙만으로 씁니다.
2. 새 회사 메일이 30통, 문서가 5건쯤 쌓이면 "말투 업데이트 해줘"라고 합니다. `update/UPDATE.md` 절차대로 분석해 회사 규칙과 모드 규칙에 나눠 반영합니다. 반영하기 전에 승인을 받습니다.
3. 이전 회사 폴더는 지우지 않고 남겨 둡니다.

문체 규칙(`email/`·`document/`)은 이 레포 작성자의 말투입니다. 자기 말투로 바꾸려면 레포를 fork한 뒤 `update/UPDATE.md` 절차로 본인 메일·문서를 분석해 규칙을 다시 재고, fork한 레포에서 설치합니다.

## 정기 업데이트

현재 회사 profile의 `last_updated`로부터 90일(`update_every_days`)이 지나면, 작업이 끝날 때 Claude가 한 줄로 업데이트를 제안합니다. 승인하면 그 사이 쓴 글로 수치를 다시 재고, 바뀐 점을 표로 보여준 뒤 승인한 것만 반영합니다. 분석용 원문은 저장소 밖 임시 폴더에만 둡니다.
