# Document Anti-patterns — AI 문서 문체 → 실제 문체

왼쪽은 본인 원본 문서에 한 번도 나오지 않은 표현이다. 대부분 AI 초안 의심 문서(2026-11 개정판, 일부 B2C 카피)에서만 보였다.

## 대조표

| AI 문체 | 실제 문체 |
|---|---|
| 한 줄 요약 — 우리는 ~를 만들었다 | 설명: ~를 구축하였습니다. (합니다체 요약) |
| ~했습니다. ~만들었습니다. (짧은 문장 연타) | ~하여 ~를 구축하였으며, ~을 확인할 수 있었습니다. (원인·결과를 한 문장에) |
| 저는 ~을 주도했습니다 | (주어 생략) ~을 전담하였습니다 / 당사 ~ |
| 따라서 / 즉 / 결과적으로 / 무엇보다 / 나아가 | 이에 / 이를 통해 / 하여 / ~을 통해 |
| ~의 정수, 완벽한, 강력한, 극대화, 치트키, 역대급, 게임체인저 | (빼고 숫자로) 10.6% → 49.4% (약 4.7배 개선) |
| ○○ 교수는 "~"라고 말합니다 / 갤럽 보고서에 따르면 | 자사 실적 수치와 기준 각주 |
| 단순히 A가 아니라 B입니다 (대구) | B를 위해 ~하였습니다 |
| 왜 ~가 중요할까요? (질문형 소제목) | **📌추진 배경** (명사구 헤더) |
| 학습 민첩성(Learning Agility) (영문 괄호 병기 남발) | 그 업무의 실무 용어를 그대로 (예: 니즈, 허들) |
| — (엠대시) | → / : / 괄호 |
| 놀라운 성과를 거두었습니다 | ▲391.04% (VAT 포함, 2026.11.12 기준) |
| 성공적으로 마무리되었습니다 (성과만) | ⚠문제 발생 → ✨개선 및 학습 |
| 측정 근거 없는 효율 향상 주장 | "별도로 측정하지 않아 수치로 기재하지 않았습니다" |
| ~함. ~임. (공문 명사형) | ~ 필요 / ~ 예정 / ~ 완료 / ~ 불가 |
| 세팅 | 셋팅 |
| ### 소제목 + 긴 줄글 | 표 먼저, `-` 불릿 2단 이내 |

### 제안서·소개서 장표

AI 초안 제안서(`_ai` 대조군, 기술평가서 56장)와 본인 제안 장표 2건을 비교했다. 왼쪽은 대조군에만 나왔다(엠대시 13회, "기반" 31회 → 본인 0회).

| AI 문체 | 실제 문체 |
|---|---|
| 클링 — 이제, 움직입니다 / 기초 개념 — 시작이 반이다 (엠대시 + 문학적 장 제목) | `첫번째 차별점 - {키워드}` (위치 표시) + 사실 헤드라인 |
| ~기반 ~ / 데이터 기반 / AI 기반 (반복) | 무엇을 하는지 동사로: "{지표} 데이터 대시보드 제공" |
| 장 제목부터 끝까지 합니다체 한 가지 | 선언은 합니다체, 혜택은 해요체 ("~지원해드려요") |
| 고객 이름 없는 범용 문안 | "{고객사} {대상}의 {목적}을 위한 2가지 서비스를 제안 드립니다." |
| 가격은 별도 문의 | 할인율·단가표·총액 + "편하게 말씀 부탁 드리겠습니다" + ※ 예시 단서 |

## 자기검수 체크리스트

- [ ] 문서 종류에 맞는 종결인가? (슬라이드·보고·회의자료·내부 = 개조식 명사 종결 / 포트폴리오·회고·협조 공문 = "~하였습니다" / 고객 제안 장표 = 선언 합니다체 + 혜택 해요체)
- [ ] 한 문서 안에서 종결이 섞이지 않았는가? (회의자료 속 결정 질문, 고객 제안 장표는 예외)
- [ ] 제안 장표라면 고객사 이름, 견적 장(할인율·총액·※ 단서), 마지막 장 문의처가 있는가?
- [ ] "저는"이 없는가?
- [ ] 성과 문장마다 숫자와 기준(시점·VAT·출처)이 붙었는가? 안 잰 것을 지어내지 않았는가?
- [ ] "따라서 / 즉 / 결과적으로 / 무엇보다 / 다만"이 없는가?
- [ ] 과장 수사·학술 인용·질문형 소제목·"A가 아니라 B" 대구·엠대시가 없는가?
- [ ] 표로 정리할 수 있는 것을 줄글로 늘어놓지 않았는가?
- [ ] 불릿이 `-` 하나, 2단 이내이고 하위 불릿에 근거만 있는가?
- [ ] 흐름은 `→`, 병렬은 `·`, 단서는 `※`, 라벨은 `항목 : 내용`인가?
- [ ] 회고·포트폴리오에 문제·학습 섹션이 있는가?
- [ ] 고객 협의 문서라면 결정할 항목을 질문으로 명시하고 우리 기본안을 함께 냈는가?
- [ ] 모르는 값(수치·기관명·일정)을 `{ }`로 비워 두었는가?
