# Situations — 상황별 뼈대와 예문

예문은 실제 메일을 익명화한 것이다. `{이름}`·`{회사}`·`{금액}` 등은 자리 표시이고, 인사·소속 줄과 서명은 `voice.md` §1·§6을 따르므로 대부분 생략했다.
표본 분포(480통): 일반 회신 138 / 견적 76 / 계약 66 / 팔로업 58 / 일정 33 / 협상 30 / 사과 13 / 정산 12 / 거절·실패·수주 9.

## 1. 일반 회신·확인
**뼈대**: "네!" → 받은 내용 확인 → 처리 결과나 다음 행동 → (생략 가능) 마무리
- 네! 전달 주신 내용 확인했으며 아래 {N}개 {항목}만 이용하실 수 있도록 준비하겠습니다.
- 상세히 공유주셔서 감사드리며 일정 부분도 인지하고 있겠습니다😊
- 조금 전 전달 주신 소재로 변경 완료하였고 게재 공유 드립니다.
- 변경된 장소 잘 확인했으며 늦지 않게 도착하도록 하겠습니다.
- 상대가 확정한 금액·조건을 한 번 더 짚는다: "건당 정산 금액은 *{금액}*으로 인지하고 있겠습니다😊"

## 2. 질문 목록에 하나씩 답하기
**뼈대**: "아래와 같이 회신 드립니다!" → 상대 질문을 그대로 옮기고 → 그 밑에 `→ 네, ~` 또는 굵은 `▶`로 답
```
추가 문의 주셔서 감사드리며 아래와 같이 답변 드립니다!

1. 이미지 수급 요청
(상대 질문 원문)

*→ 로고 및 {자료} 이미지 첨부 드립니다.*

2. 게시 일정
(상대 질문 원문)

*→ 네, 소재 전달 일정에 맞춰 수령 후 2영업일 내 셋팅 및 라이브 예정입니다.*
```
- 기관 공문·보안 점검 회신은 이모지 없이 `*▶ 당사 서비스 중에 ~를 사용하는 서비스는 없습니다.*`처럼 쓴다.

## 3. 견적
**뼈대**: 감사 + "요청 주신 ~ 반영하여 견적서 전달 드립니다" → 조건 불릿 → 다음 단계 한 줄
```
추가 이용 문의 주셔서 감사드리며 이전 3개월 이용 단가와 동일한 견적 반영하여 견적서 전달 드립니다!

   - *상품명* : {서비스명}
   - *상세 내용* : {한 줄 설명}
   - *단가* : {과금 단위} 기준 {정가}원 → *{할인가}원* (vat별도)
      - 도입 인원 및 기간에 따라 최대 *{N}%*의 기업 추가 할인율이 적용될 수 있습니다.

※ 실제 {조건} 확정 시 {변수} 등에 따라 변동될 수 있습니다.
```
- 예산에 맞출 때: "말씀 주신 예산에 맞춰 견적서 전달 드리며 이후 {결제 담당 부서}에서 연락 주시면 결제 처리 후 {이용권} 전달 드리겠습니다!"
- 기존 고객 재계약: "저희 서비스 지속 이용해주시는 점에 감사드리며 *기존과 동일한 단가*로 제공해드리겠습니다!"

## 4. 계약·정산
**뼈대**: 전달 사실 → `<계약서>` 같은 꺾쇠 섹션 + 불릿 → 수정 여지를 열어 둠 → 필요 서류 요청
```
<계약서>
   - 기협의된 {과금 단위} 기준 {금액}원(vat별도)으로 이용 금액 반영하였으며 견적서도 함께 전달 드립니다.
   - 서비스 이용 기간은 12/1(월) ~ 12/31(수)로 기재하였으며 시작 일자 변경이 필요하다면 말씀 부탁 드리겠습니다.
   - 계약서 검토 후 이상 없으실 경우 전자계약 또는 실물 날인 등 편하신 방법으로 의견 주시면 진행하도록 하겠습니다.
```
- 상대 수정안 회신: "전체적인 수정 사항은 이견 없으며 {N}조 {N}항 ~에 대한 부분만 메일로 공유 주시면 검토 후 회신 드리겠습니다."
- 확인 완료: "전달 주신 계약서 잘 확인했으며 이상 없습니다😊"
- 정산 요청: "계산서 발행을 위해 사업자등록증 1부 전달 부탁 드리며 금일 중으로 발행하도록 하겠습니다."
- 지급 일정 안내: "입금은 {날짜}에 진행될 예정인 점 참고 부탁 드리겠습니다!"
- 외부 협력자 정산 안내는 표나 불릿으로 `{작업} 일정 / 총 지급액 (VAT 포함) / 세금계산서 발행 메일 / 작성 일자 / 요청 서류`를 정리한다.

## 5. 일정 확정·제안
- 확정: "네! ~ 확인했으며 *차주 금요일 11시*에 비대면으로 뵙도록 하겠습니다😊" 다음 줄에 `▶ 화상 미팅 링크 : {URL}`
- 제안: "{M/D(요일)}~{M/D(요일)} 오후 일정이 괜찮은데 혹시 가능하실까요? 조정 필요하시다면 편하게 말씀 부탁 드리겠습니다."
- 사전 안내(행사·현장 진행): 한 줄 소개 → `- *항목* : 값` 불릿(일정·주제·장소·인원·준비 사항) → `확인 요청 사항` 불릿 → 마무리.

## 6. 미팅·통화 후 정리
**뼈대**: 시간 내준 데 대한 감사 + "정리하여 전달 드립니다" → 불릿 → 다음 단계
- 금일 바쁘신 와중에도 귀한 시간 내주신 점 다시 한번 감사드리며, 미팅 간 말씀 드린 자료 정리하여 전달 드립니다!
- 유선으로 논의 나눈 사항 아래와 같이 정리하여 회신 드립니다😊
- 협업안이 여러 개면 `- *협업 1안 - {이름}*`처럼 굵은 라벨 아래 설명을 한 줄씩 단다.

## 7. 팔로업
**뼈대**: 근황 안부 → "~여쭙고자 메일 드립니다" → 새 정보 하나 → 마무리
```
지난 여름 미팅 이후 오랜만에 메일 드립니다! 잘 지내셨을까요😊

다름이 아니라 차년도부터 {상대 계획}에 {자사}를 추가하실 예정이라고 지난번 말씀 주셨는데,
내부 준비 간 저희가 미리 챙길 부분은 없을지 여쭙고자 메일 드리게 되었습니다.

최근 {새 소식 한 줄, 숫자 포함} {자료} 파일도 함께 전달 드립니다!
```
- 견적 후 무응답: "지난번 요청 주신 견적서 전달 드린 후 추가로 도움 드릴 사항은 없을지 여쭙고자 메일 드립니다!"
- 서명 독촉: "아직 확인을 못하신 듯 하여 메일 드립니다!" / "서명 만료 일자가 이번주까지라 부득이하게 요청 드립니다!"
- 요청은 하나만, 가장 작게: "혹시 {자료} 전달 시점을 간단하게 공유 받을 수 있을지 문의 드립니다."

## 8. 협상·가격
**뼈대**: 상대 입장 인정 → "다만" + 우리 조건과 이유 한 줄 → 조정 여지나 대안을 먼저 제시
- {다른 상품}의 경우 {조건}이 포함되어 있어 상대적으로 할인율이 큰 점 이해 부탁 드리겠습니다😊
- 단가 같은 경우에도 내부 예산이 한정되어 있으시다면 *추가 조정*을 도와드릴 수 있으니 편하게 검토 후 의견 부탁 드리겠습니다.
- 다만 양사가 개발 부담이 있을 수 있어 어렵다면 내부적으로 정산 데이터를 보정하는 등의 방안으로 고려해볼 수 있으니 편하게 확인 부탁 드리겠습니다.
- 수량·기간 조정에 따라 1건 당 대여비를 일부 상향 조정한 점 양해 부탁 드리겠습니다.
- **가격 인상 안내**: 안부·감사 → `*<가격 인상 안내>*` → 인상 근거를 숫자로(제공 범위 확대, 비용 상승) → `- *정가 인상 안내* : {이전} → *{이후}* (vat별도)` → `- *신규 단가 제안*` → `- *적용 혜택 안내*`

## 9. 사과
상황의 무게에 따라 세 단계로 쓴다.

**① 본인의 작은 실수** (재첨부·정정) — 인사·소속 생략 가능, 😅 가능
```
과장님! 엑셀 파일을 잘못 전달드렸네요😅
해당 파일로 확인 부탁 드리겠습니다!

감사합니다.
```
- 지연: "외부 일정으로 인해 회신이 늦어진 점 양해 부탁 드리겠습니다." 한 줄 뒤 바로 본론.

**② 서비스 오류** — 이모지 없음. 사과 1문장 → 원인 → 조치 완료 → 추가 확인 요청
```
이용에 불편을 드려 죄송합니다.
내부 확인 결과 {기능} 설정 시 {제한}을 *최대 2회*까지로 두어 발생한 이슈로 확인되었습니다.

이용 편의를 위해 {제한}을 *최대 100회*까지로 수정 완료하였습니다.
브라우저 새로고침 후 다시 {작업}을 하시면 정상적으로 사용이 가능하실 것 같습니다.
혹시 추가 이슈가 있다면 편하게 말씀 부탁 드리겠습니다.
```

**③ 큰 사고** (데이터 유실, 대외 배포 사고) — 조치 결과 → 사과 → 재발 방지 → 재사과
```
1차 {서비스} 데이터 오류 관련하여 논의 나눴던 데이터 외 일부 데이터도 유실 정황이 발견되어
조금 전 모든 데이터 검수하여 원복 처리 완료하여 공유 드립니다!

불편을 드린 점 다시 한번 죄송하다는 말씀 드리며 2차 운영에는 불편함이 없도록
개발팀과 긴밀히 협력하여 오류 조치하도록 하겠습니다.
```

## 10. 거절·우회
**뼈대**: 감사 → "다만" + 내부 사유(유관부서·내부 정책·리소스) → "어려울 것으로 보입니다 / 어렵다고 회신 받았습니다" → 가능한 대안이나 다음 기회. 서명은 `{name} 드림.`, 이모지는 감사 문장에 많아야 1개.
- 문의 주신 사항에 대해 유관부서와 상세히 논의나누었습니다. 다만 현재 해당 팀에서 진행하고 있는 운영 프로세스 상 요청 주신 프로그램 핸들링이 불가하여 진행이 어렵다고 회신 받았습니다. 양해 부탁 드리며 ~ 부분은 진행 가능하오니 편하게 회신 부탁 드리겠습니다.
- 우선 좋은 기회 주신 점 진심으로 감사드립니다😊 다만 금번 입찰 제안에는 내부 리소스 상 참여가 제한되어 아쉽지만 다음 기회에 다시 인사를 드려야 할 것 같습니다.
- 희망하시는 방안과는 다소 차이가 있어 보시고 추가 의견이 있으시다면 편하게 말씀 부탁 드리겠습니다.
- 저희 내부 {업무}와는 조금 거리가 있을듯 하나 저희 팀에서 담당하는 고객사 {프로젝트} 진행 시 니즈가 맞는다면 매칭을 도와드릴 수 있을 것 같습니다.
- **인바운드 제안 접수** (2~3문장, 팀 명의 서명): "좋은 제안 주셔서 감사드리며 해당 내용은 유관부서에 전달 드리도록 하겠습니다. 해당 팀에서 추가 논의가 필요하실 경우 연락 드릴 예정입니다!"

## 11. 수주
**뼈대**: 결정 감사😊 → 상대 조직에 줄 효과 한 줄 → 계약·셋팅 다음 단계를 섹션 불릿으로
- 저희 서비스 도입을 결정해주셔서 진심으로 감사드립니다😊
- {회사} {대상}의 {목표}에 {company}가 큰 힘이 될 수 있도록 노력하겠습니다!
- 이어서 `<계약서>`, `<이용 관련>` 섹션 (4번 참고)

## 12. 수주 실패
**뼈대 A** (상대가 거절을 알려 왔을 때): 회신 감사😊 → 다음 기회 고대 → 마무리
```
회신 주셔서 감사드립니다😊
추후 기회가 닿을 때 {회사} {대상}의 {목표}에 함께할 수 있기를 고대하겠습니다.

이후에도 서비스 관련 문의가 있다면 언제든 편하게 말씀 부탁 드리겠습니다!
```
**뼈대 B** (입찰 탈락을 확인했을 때): 확인 사실 → 감사 + 건승 기원 → 피드백 요청
```
금번 {프로젝트} 도입 건 관련하여 아쉽게도 수주하지 못한 부분 입찰 시스템을 통해 확인하였습니다.
최초 미팅부터 긴 시간 제안에 도움 주신 점 다시 한번 감사드리며 앞으로도 {회사}의 건승을 빌겠습니다!

혹시 가능하시다면 추후 더 나은 제안을 위해 이번 평가에서 저희가 부족했던 부분에 대해 간략하게라도 피드백 받을 수 있을까요?
```

- 저희 서비스에 관심 갖고 문의 주셔서 진심으로 감사드립니다😊

## 14. 사내 동료·포워드
- `{이름}님~ 메일 히스토리 전달 드립니다!`
- `안녕하세요 {이름}님~ ~ 문의가 왔는데 혹시 몰라 공유 드립니다~`
- 고객에게 포워드할 때: `안녕하세요 팀장님!` → 두 줄 설명 → `감사합니다.` (소속 줄 생략)
- 인사·서명 없이 한두 줄. 물결표(~)를 쓴다.
