# Voice — 어휘·문장·기호 규칙

괄호 속 숫자는 근거다. 직접 쓴 1:1 메일 **926통**(2025-11~2026-10 480통 + 2025-03~10·2026-11 446통) 중 해당 표현이 나온 메일 비율이다. 두 표본에서 수치가 거의 같아, 이 규칙은 시기·고객이 바뀌어도 유지되는 말투로 본다.

## 1. 뼈대

```
안녕하세요 {이름} {직급}님!
{company} {team} {name}입니다.

(선택) 안부 한 줄😊

{감사/인정} + {결론} 한 문장
(필요하면) 상세 — 줄글 또는 불릿

기타 문의 사항은 언제든 편하게 말씀 부탁 드리겠습니다!

감사합니다.
{서명}
```

- **인사 줄**: `안녕하세요 {이름} {직급}님!` 형식이고 끝에 느낌표를 붙인다. 이름을 모르면 `{직급}님!` 또는 `담당자님!`. 벤더·오래 거래한 실무자에게는 `안녕하세요 팀장님~`처럼 물결로 끝내기도 한다. 수신자가 둘이면 `안녕하세요 {A} 팀장님, {B} VP님!`
- **인사 줄과 소속 줄 사이에는 빈 줄을 두지 않는다.** 소속 줄 다음에는 빈 줄을 둔다.
- **소속 줄은 거의 항상 쓴다** (약 90%). 생략하는 경우: 같은 날 이어 보내는 정정·재첨부, 사내 메일, 고객에게 포워드할 때.
- **안부 줄** (선택): 고객·기관에게, 오랜만에 연락하거나 주말·명절·연말 직후일 때. 의문형으로 쓰고 끝에 😊를 붙인다.
  - "즐거운 주말 보내셨을까요😊" / "그간 잘 지내셨을까요😊" / "연말 마무리 잘 하고 계실까요😊"
  - "날씨가 많이 쌀쌀해졌는데 항상 건강 유념하시길 바라겠습니다😊"
  - 사과·거절·공문·짧은 회신에는 넣지 않는다.
- **마무리 상투구** (약 50%): "기타 문의 사항은 언제든 편하게 말씀 부탁 드리겠습니다!" 변형으로 "추가 문의 사항은~", "그 외 필요하신 부분은 언제든 편하게 말씀 부탁 드리겠습니다!", 파트너·벤더에게는 "~편하게 말씀 주세요!"(14.6%). 짧은 확인 회신은 생략해도 된다.
- **맺음**: "감사합니다."(653회)와 "감사합니다!"(507회)를 둘 다 쓴다. 사과·공식 회신은 마침표, 밝은 회신은 느낌표.

## 2. 문장

- **두 절은 "~며"로 잇는다.** "~드리며"(35.4%), "~했으며/하였으며"(11.8%). 쉼표는 거의 쓰지 않는다.
  - "요청 주신 계약서 수정 사항 반영했으며 최종본 공유 드립니다."
  - "회신 주셔서 감사드리며 아래와 같이 답변 드립니다!"
- **한 줄에 한 문장.** 긴 문장은 의미 단위에서 손으로 줄을 바꾼다.
- **문단은 1~2문장.** 문단 사이는 빈 줄로 띄운다.
- **본문 길이**(인사·서명 제외): 중앙값 265자, 보통 180~450자. 짧은 확인 회신은 2~3문장으로 끝낸다.
- **다음 행동은 시점과 함께 약속한다.** "금일 중으로 발행하도록 하겠습니다", "내일 오전까지 전달 드리겠습니다." ("~도록 하겠습니다" 33.8%)
- **완곡 표현**: "~것 같습니다"(8.8%)는 제안·의견에, "~것으로 확인됩니다/보입니다"는 사실 확인에 쓴다.
- **의견과 사실을 구분한다.** 개인 의견에는 "(개인적인 의견이니 참고만 부탁 드리겠습니다)"를 붙인다.

## 3. 어휘

| 쓴다 | 쓰지 않는다 |
|---|---|
| **추가로** (29.0%) | 아울러 (0.3%) / 문장 첫머리 "또한"은 드물게(약 2%), 추가로가 7배 많다 |
| **다만** (10.1%) — 반대·조건 | 하지만, 그러나 |
| **혹시** (15.1%) — 요청·질문 쿠션 | |
| **우선** (6.7%) — 사과·핵심 먼저 | 먼저 말씀드리면 |
| **하여** (문장 첫머리, 가끔) | 따라서, 그러므로, 그래서 (0~0.7%) |
| **저희**(22.9%), **당사**(8.1%), **양사**, **{회사}측** | 귀사 (1%. 계약서 수정 요청 같은 공문 성격 메일에서만) |
| **편하게** (69.6%) | 주저하지 마시고 (0회) |
| **간단하게** (9.8%) — "간단하게 확인 부탁" | |
| **~주신** (48.0%) — 요청/문의/전달/말씀/공유 주신 | 요청하신, 말씀하신 |
| **양해 부탁 드리겠습니다** (8.6%) | 너그러운 이해 바랍니다 |
| **고대하겠습니다** — 다음 기회·협업 | 기대하겠습니다 |
| **여쭙고자 메일 드립니다** — 팔로업 | ~하고자 합니다 (1.0%, 기본형으로 쓰지 않음) |
| **귀한 시간 내주셔서** | 소중한 시간 (0회) |

- **같은 쿠션어를 반복하지 않는다.** "편하게"는 926통에 786회, 메일당 1회 안팎이고 보통 마무리 상투구에만 나온다. 본문 요청에는 "혹시", "간단하게"를 쓴다.
- **"또한"은 조사처럼만 쓴다**: "관리자 권한 또한 부여해드릴 예정이며". 문장을 "또한,"으로 시작하지 않는다.
- **"최선을 다하겠습니다"**(0.3%)는 수주·재계약 감사 메일에서만 쓴다.
- **"혁신"**은 사업명·기관명 같은 고유명사 안에만 나온다. 수식어로 쓰지 않는다.
- **업무 시간어**: 금일, 익일, 전일, 금주, 차주, 전주, 익월. "유선으로"(전화로), "기협의된/기전달 드린", "날인", "기안 상신". (업종 용어는 회사 profile)
- **날짜 형식**: `11/25(화)`, `2026.10.29(목) 오후 1시~4시`, 기간은 `12/1(월) ~ 12/31(수)`.
- **금액 형식**: `30,000원(vat별도)`, `2,000,000원 (VAT 포함)`. 할인은 `59,000원 → *30,000원*`처럼 화살표로.

## 4. 띄어쓰기 — 본인 표기 습관

| 띄운다 | 붙인다 |
|---|---|
| 전달 드립니다 (698회 vs 붙임 44회) | **감사드립니다** (437회, 띄움 4회) |
| 부탁 드리겠습니다 (1,207회 vs 붙임 143회) | 인사드리며 |
| 말씀 드립니다, 공유 드립니다, 회신 드립니다, 연락 드리겠습니다 | |
| 문의 드립니다 (띄움 쪽이 많음) | |

## 5. 기호·이모지·서식

- **이모지**: 메일당 0개(37%) 또는 1개(58%). 종류는 사실상 😊(569회) 하나다.
  - 😊 — 안부 줄 끝, 또는 첫 감사·긍정 문장 끝. 이모지 뒤에는 마침표를 찍지 않는다: "감사드립니다😊"
  - 😅 — 본인 실수·지연을 가볍게 인정할 때만: "엑셀 파일을 잘못 전달드렸네요😅", "연차로 회신이 늦은 점 양해 부탁 드리겠습니다😅". 내 사정으로 늦은 회신은 😊가 아니라 😅다.
  - 😢 — 아쉬운 결과(성과 부진 등)에 드물게.
  - **이모지를 안 넣는 메일**: 서비스 오류 사과(13통 중 3통만 이모지), 거절, 기관 공문 회신, 임원에게 짧게 전달하는 메일.
- **느낌표**: 메일당 2~3개(약 78%). 인사 줄, 요청 끝("~부탁 드리겠습니다!"), 맺음에 붙는다. 본문 한가운데에는 거의 없다.
- **굵게** (`*텍스트*`, 37.9%의 메일): 금액·할인율·기한·핵심 조건·상품명만. 쓰는 메일에서는 여러 번 쓴다.
- **불릿** (25%의 메일): 사실이 3개 이상(금액·수량·기간·절차·질문)일 때만. 형식은 `- *라벨* : 값`이고, 근거·예외는 하위 불릿으로 단다.
- **혜택·첨부 목록**: 혜택·상품 머리는 `*📌 {상품명}*`, 첨부 자료 목록은 `· 📋 *{자료명}*`처럼 줄머리에만 쓴다. 본문 문장 속 이모지로 세지 않는다.
- **긴 메일의 섹션 머리**: `<계약서>`, `<이용 관련>`, `*<가격 인상 안내>*`처럼 꺾쇠를 쓴다. `###` 같은 마크다운 소제목은 쓰지 않는다.
- **→ / ▶**: 상대 질문에 하나씩 답할 때("→ 네, ~"), 링크 앞("▶ 미팅 링크 : {URL}"), 흐름 표시("쿠폰 구매 > 관리자 페이지 안내").
- **※**: 단서·주의 사항 한 줄. "※ 실제 {조건} 확정 시 {변수}에 따라 변동될 수 있습니다."
- **줄표(—)는 쓰지 않는다.** 콜론으로 문장을 끝내지 않고 "아래와 같이 회신 드립니다!"처럼 쓴다.

## 6. 수신자별 차이

| 수신자 | 인사 | 서명 | 이모지·안부 | 말투 |
|---|---|---|---|---|
| 고객사 담당자 | `{이름} {직급}님!` | `{고객 서명}` | 😊 1개, 안부 가능 | 기본 |
| 기관·공공 (공문 성격) | `안녕하세요!` 또는 `{직급}님!` | 진행 중이면 `{고객 서명}`, 공문 회신은 팀 명의 | 없음 | 번호 + ▶ 답, 구조화 |
| 임원 (VP·상무) | `{이름} {직급}님!` | `{name} 드림.` | 짧은 전달이면 없음 | 구조 동일, 더 짧게 |
| 파트너·제휴사 | `{이름} {직급}님!` | `{name} 드림.` | 가끔 | 더 솔직하고 실무적. 내부 사정도 공유 |
| 벤더 (인쇄·제작 등) | `팀장님!`, `실장님~` | `{name} 드림.` | 가끔 | 짧고 직접적. 납기·수량·계산서 일자 명시 |
| 개인 협력자 (강사·프리랜서·작가 등) | `{이름} 님!` | `{name} 드림.` 또는 팀 명의 | 😊 | 존중 표현↑, "조심스럽게 문의 드립니다" |
| 사내 동료 | `{이름}님~` | 없음 | 없음 | 한두 줄. "~공유 드립니다!" |
| 영어 (해외 파트너) | `Hi {Name},` | `Best regards,` + `{name_en}` | 없음 | 아래 참고 |

**영어 메일**
- `Hi {Name},` → (첫 메일이면) `I hope you are doing well.` → 바로 용건.
- 짧고 솔직하게 쓴다: "Things have been quite busy with other company priorities lately, so I couldn't get to this as quickly as I'd hoped."
- 요청은 `could you please ~?`, 수정 사항은 번호 목록, 마무리는 `We look forward to ~!` 한 줄.
- 한국어 인사·서명 관습(드림, 고객 서명)을 옮겨 쓰지 않는다.

## 7. 제목

- 새 메일: `{subject_prefix} {고객사} {용건}의 건` — 예: `[자사] {회사} 서비스 견적 안내의 건`
- 견적서·계약서처럼 버전이 있는 문서는 끝에 `_YYMMDD`를 붙인다: `~ 견적 안내의 건_261029`
- 상대가 연 스레드에 답할 때는 상대 제목을 그대로 두고 `Re:`만 붙는다.
- 1:1 메일 제목에는 이모지를 넣지 않는다. 콜드메일 제목 규칙은 `cold-outreach.md`.
