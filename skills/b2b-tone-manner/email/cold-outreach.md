# Cold Outreach — 콜드메일·대량 발송

본인이 직접 쓴 세일즈 시퀀스 템플릿 16종을 분석했다. 마케팅팀이 자동 발송한 너처링 메일(`*강조*` 남발, "연 {금액} 상당", "어떤 조건도 없이 무제한!", 업종을 추정한 자동 생성 문장)은 본인 톤과 달라서 제외했다.

1:1 메일 규칙(`voice.md`)이 기본이고, 아래는 콜드메일에서 **달라지는 점**만 적었다.

## 1. 제목 공식

`{subject_prefix} {이름}님 / {회사} + 혜택 명사구 + 드립니다·소개합니다 + 😊`

- `[자사] {회사} 맞춤 {자료}와 {무료 혜택}을 전달 드립니다!`
- `{이름}님, {상대 지표}를 높이는 {서비스 분류}를 소개합니다😊`
- `[자사] {회사}의 {진단 항목}은 몇 점일지 지금 바로 확인해보세요!`
- `[자사] {회사} {대상}을 위한 {무료 체험} 이벤트에 당첨되셨습니다🎉`
- 개인화 변수(이름·회사)는 제목 앞쪽에 둔다. 제목 끝 이모지는 😊 하나(당첨·축하만 🎉).

## 2. 본문 흐름

```
안녕하세요 {이름} {직급}님!
{company} {team}에서 {담당 업무}를 담당하고 있는 {name} {title}입니다.

{접점 한 문장}               ← 신청·참석·다운로드·부스 방문·이전 미팅
{상대 고민을 추정형으로 짚기}   ← 단정하지 않는다
{제안 한 문장}

✅ {숫자 + 명사로 된 혜택 1}
✅ {혜택 2}
✅ {혜택 3}

{실행 방법: 방법1/방법2 또는 1-2-3 단계}  (필요할 때)
{약한 CTA}

추가로 궁금하신 점이 있으면 언제든 편하게 말씀 부탁 드리겠습니다!

감사합니다.
{고객 서명}
```

### 접점으로 시작한다 — 접점 없는 첫 문장은 쓰지 않는다
- {service} 서비스에 관심 가져주셔서 감사드리며 저희 서비스 소개서를 추가로 전달 드립니다!
- 앞서 제공해드린 {체험 서비스} 이용에 불편함은 없으실까요😊
- 지난번 웨비나에 참석해주셔서 감사드리며 발표 자료를 전달 드립니다😊

### 고민은 추정형으로
- 현재 저희 서비스 도입에 대한 예산 및 {기대 효과} 등에 대해 내부 고민이 많으실 것으로 예상되는데요!
- 차년도 {관련 계획}을 준비 중이실 것 같아 ~
- 체험 사용자의 실제 행동을 근거로 할 때: "~ {기능}을 집중 사용하시는 걸로 확인이 되는데요!"

### 혜택은 ✅ 3~4줄, 숫자 + 명사
```
✅ {수단}을 통한 {측정·진단}
✅ {핵심 제공물} 제시
✅ 대시보드를 통한 {현황} 모니터링
```
- 다음에 가치를 한 문장으로 요약한다: "등을 통해 {상대 담당자}들의 운영 부담은 낮추고, {효과}는 높이는 체계로 운영되고 있습니다."
- 제목 블록을 쓸 때는 `[{회사} {무료 체험} 제안]` 한 줄 뒤에 ✅를 이어 단다.
- 상품·콘텐츠 소개는 `🔧 / 🤖 / 📊 {제목}` + 설명 두 줄 + `👉 링크` 형식으로 쓴다.

### CTA는 약하게, 실행은 쪼개서
- 보다 자세한 상담을 위해 빠른 시일 내에 유선으로 연락 드릴 수 있도록 하겠습니다.
- 부담 없이 의견 주시면 {회사} {대상}께서 만족하실 수 있는 서비스를 제공하기 위해 노력하겠습니다.
- {자료} 전달이 어려우시다면 2번 방법으로 진행을 추천 드립니다.
- 혹시 내부적으로 업무가 바쁘셔 체험 일정 조정이 필요하시다면 편하게 말씀 부탁 드리겠습니다.

### 마무리 직전 한 줄 (선택)
- {service}가 {이름}님 회사의 {고민} 해결에 도움이 될 수 있길 바랍니다.
- {회사} {대상}께 큰 힘이 될 수 있기를 고대하겠습니다.

## 3. 1:1 메일과 다른 점

| 항목 | 1:1 메일 | 콜드메일 |
|---|---|---|
| 소속 줄 | `{company} {team} {name}입니다.` | `~팀에서 {담당 업무}를 담당하고 있는 {name} {title}입니다.` |
| ✅ 불릿 | 거의 안 씀 (0.6%) | 혜택 3~4줄 |
| 숫자 강조 | 조건·금액 | `{N}+개 {상품}`, `매월 {N}개 이상` 같은 규모 (실제 숫자는 회사 profile) |
| 고민 짚기 | 상대가 말한 사실 | 업계 일반론을 추정형으로 |
| 첨부 | 상황에 따라 | 소개서·상품 리스트·사례집을 거의 항상 첨부 |
| 제목 이모지 | 없음 | 끝에 😊 |

## 4. 콜드메일에서도 쓰지 않는 것

- 기한 압박: "오늘까지", "선착순", "마감 임박"
- 경쟁사 비교, 최상급 남발("압도적", "업계 최고")
- 마케팅 수사: "혁신적인", "게임체인저", "~의 모든 것", "어떤 조건도 없이 무제한!"
- 단정형 진단: "귀사는 지금 AI 전환이 시급합니다" → "~ 고민이 많으실 것으로 예상되는데요!"
- 영어 버즈워드는 AX·KPI 정도까지만 쓴다.
