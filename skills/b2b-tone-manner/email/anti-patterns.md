# Anti-patterns — AI 번역투 → 실제 표현

AI가 쓴 B2B 메일이 어색한 이유는 대부분 아래 패턴 때문이다. 왼쪽은 926통에서 0~1회만 나왔거나 아예 나오지 않은 표현이고, 오른쪽은 실제로 쓰는 표현이다.

## 대조표

### 도입부
| AI 번역투 | 실제 표현 |
|---|---|
| 안녕하세요, {이름}님. {company}의 {name}입니다. | 안녕하세요 {이름} {직급}님!⏎{company} {team} {name}입니다. |
| 다름이 아니라 ~에 대해 말씀드리고자 연락드렸습니다. | (예고 없이 바로) 요청 주신 견적서 전달 드립니다! |
| 지난번 말씀하신 대로 ~를 요청하셨는데요, 이에 대해 ~ | 요청 주신 ~ 반영하여 전달 드립니다. |
| 소중한 시간 내주셔서 진심으로 감사드립니다. 귀사와의 미팅은 매우 유익했습니다. | 바쁘신 와중에도 귀한 시간 내주셔서 감사드리며 미팅 간 논의 나눈 사항 정리하여 전달 드립니다! |
| 메일 잘 받았습니다. 보내주신 내용 꼼꼼히 확인했습니다. | 네! 전달 주신 내용 확인했으며 ~ 하도록 하겠습니다. |

### 본문
| AI 번역투 | 실제 표현 |
|---|---|
| 귀사 | {회사}, {회사}측, 저희/당사 |
| 또한, ~ / 아울러 ~ | 추가로 ~ |
| 따라서 ~ / 그러므로 ~ | 하여 ~ / "~하여 ~드립니다"로 한 문장에 잇기 |
| 하지만 ~ | 다만 ~ |
| ~하시기 바랍니다 | ~부탁 드리겠습니다 |
| ~해 주시면 감사하겠습니다 (모든 요청에) | 간단하게 ~ 부탁 드려도 될까요? / 혹시 ~ 가능하실까요? |
| 다음과 같습니다: | 아래와 같이 정리하여 전달 드립니다! |
| 첫째, ~ 둘째, ~ 마지막으로, ~ | 1. / 2. 번호 또는 `- *라벨* : 값` 불릿 |
| ### 요약 / 결론적으로 / 정리하면 | (쓰지 않는다. 결론은 이미 첫 문장에 있다) |
| 혁신적인 솔루션으로 업무 효율을 극대화하고 시너지를 창출 | 월 {N}개 이상 {업데이트}, {과금 단위} {금액}원(vat별도) |
| 최적의 / 최고의 / 탁월한 | (빼고 숫자로) |
| — (줄표) | 쉼표 없이 "~며"로 잇거나 괄호 |
| 문단마다 감사 표현 반복 | 감사는 첫 문장 한 번 |
| 항목이 2개뿐인데 불릿 | 줄글 한 문장 |
| 한 메일에 이모지 여러 개 (🚀✨👍) | 😊 하나, 또는 없음 |
| 확인 부탁드립니다 / 전달드립니다 | 확인 부탁 드리겠습니다 / 전달 드립니다 (띄움) |
| 감사 드립니다 | 감사드립니다 (붙임) |

### 사과·거절
| AI 번역투 | 실제 표현 |
|---|---|
| 불편을 드렸다면 진심으로 사과드립니다. (조건부 사과) | 우선 이용에 불편을 드린 점 죄송하다는 말씀 드립니다. |
| 많이 당황스러우셨을 것 같습니다. 고객님의 마음 충분히 이해합니다. | (공감 문장 없이) 원인 → 조치 완료 |
| 이번 일을 계기로 더욱 발전하는 ~가 되겠습니다. | 이후에는 불편함이 없도록 개발팀과 긴밀히 협력하여 조치하도록 하겠습니다. |
| 아쉽지만 요청하신 사항은 진행이 불가능합니다. | 다만 현재 ~ 프로세스 상 ~ 진행이 어렵다고 회신 받았습니다. 양해 부탁 드리며 ~는 진행 가능하오니 편하게 회신 부탁 드리겠습니다. |
| 답변이 늦어져 대단히 죄송합니다. 여러 업무가 겹쳐 ~ (긴 변명) | 외부 일정으로 회신이 늦어진 점 양해 부탁 드리겠습니다. (한 줄) |

### 마무리
| AI 번역투 | 실제 표현 |
|---|---|
| 궁금하신 점이 있으시면 언제든지 연락 주시기 바랍니다. | 기타 문의 사항은 언제든 편하게 말씀 부탁 드리겠습니다! |
| 주저하지 마시고 문의해 주세요. | ~편하게 말씀 주세요! |
| 도움이 되셨으면 좋겠습니다. 좋은 하루 보내세요! | (쓰지 않는다. 필요하면 "미리 즐거운 주말 되시길 바라겠습니다!") |
| 앞으로도 많은 관심과 성원 부탁드립니다. | (쓰지 않는다) |
| {name} 드림 / {name} 올림 | {고객 서명} / {name} 드림. (마침표까지) |

## Before / After

### 예 1. 견적 회신

**Before (AI)**
```
안녕하세요, 김OO 대리님.
{company}의 {name}입니다.

다름이 아니라 지난번 요청하신 견적서와 관련하여 말씀드리고자 연락드렸습니다.
귀사의 소중한 관심에 진심으로 감사드립니다.

요청하신 내용을 꼼꼼히 검토한 결과, 다음과 같이 견적을 산정하였습니다:
- 인원: 23명
- 기간: 3개월

또한, 기존 이용 고객이신 점을 고려하여 이전과 동일한 단가를 적용해 드렸습니다.
이를 통해 귀사의 {목표} 달성에 최적의 솔루션이 될 것이라 확신합니다.

궁금하신 점이 있으시면 언제든지 연락 주시기 바랍니다.
감사합니다.
{name} 드림
```

**After**
```
안녕하세요 김OO 대리님!
{company} {team} {name}입니다.

즐거운 주말 보내셨을까요😊
추가 이용 문의 주셔서 감사드리며 이전 3개월 이용 단가와 동일한 견적 반영하여 견적서 전달 드립니다!

기타 문의 사항은 언제든 편하게 말씀 부탁 드리겠습니다.

감사합니다!
{고객 서명}
```
바뀐 점: 예고문과 감사 반복을 지웠다. 23명·3개월은 상대가 보낸 값이라 다시 늘어놓지 않았다. "귀사·또한·최적의·연락 주시기 바랍니다"를 뺐다. 서명을 고객용으로 바꿨다.

### 예 2. 서비스 오류 사과

**Before (AI)**
```
안녕하세요, 진OO 과장님.

먼저 이용에 불편을 드렸다면 진심으로 사과의 말씀을 드립니다. 많이 당황스러우셨을 것 같습니다.
확인해 본 결과, 시스템상의 일시적인 오류로 인해 이용 권한이 누락된 것으로 파악되었습니다. 현재는 해당 문제를 해결하여 권한을 다시 부여해 드렸습니다. 😊🙏

아울러 말씀하신 '참여하기' 버튼의 위치를 알려주시면 보다 신속한 조치가 가능할 것 같습니다.
앞으로 이런 일이 재발하지 않도록 최선을 다하겠습니다.

추가로 궁금하신 점이 있으시면 주저하지 마시고 연락 주세요!
```

**After**
```
안녕하세요 진OO 과장님!
{company} {team} {name}입니다.

우선 이용에 불편을 드린 점 죄송하다는 말씀 드립니다.
현재 이용 권한이 시스템 오류로 누락된 것으로 보여 다시 재부여 완료하였습니다.

추가로 말씀 주신 참여하기 버튼은 어디에서 클릭하신 버튼일까요?
자세한 오류 조치를 위해 문의 드리며 유선으로 도움이 필요하시다면 편하게 말씀 부탁 드리겠습니다!

감사합니다.
{고객 서명}
```
바뀐 점: 조건부 사과와 공감 문장을 지우고 사과 → 원인 → 조치 순서로 바꿨다. 사과 메일이라 이모지를 뺐다. "아울러"를 "추가로"로 바꾸고 질문은 직접 묻는 형태로 썼다.

## 자기검수 체크리스트

내기 전에 하나씩 확인한다.

- [ ] 소속 줄 다음 첫 문장이 용건인가? (예고문·받은 메일 요약이 없는가)
- [ ] 감사 표현이 한 번뿐인가?
- [ ] "귀사 / 또한, / 아울러 / 따라서 / 그래서 / 하시기 바랍니다 / 주저하지 / 소중한 / 혁신적 / 최적의"가 없는가?
- [ ] 문장을 "~며"로 이었고, 문단이 1~2문장인가?
- [ ] 상대가 준 것을 "~주신"으로 받았는가?
- [ ] "편하게"가 메일 전체에서 1~2회 이하인가? (같은 쿠션어 반복 금지)
- [ ] 이모지가 0~1개이고 상황(사과·거절·공문이면 0개)에 맞는가?
- [ ] 불릿은 사실이 3개 이상일 때만 썼는가? 마크다운 소제목·줄표가 없는가?
- [ ] 숫자·날짜·금액 형식이 `11/25(화)`, `30,000원(vat별도)`인가?
- [ ] 띄어쓰기: "전달 드립니다 / 부탁 드리겠습니다"는 띄우고 "감사드립니다"는 붙였는가?
- [ ] 마무리 상투구 → "감사합니다." → 수신자에 맞는 서명(마침표 포함)인가?
- [ ] 모르는 값을 지어내지 않고 `{ }`로 비워 두었는가?
- [ ] 주어진 사실에 없는 제안·약속("수정이 필요하시면 바로 반영하겠습니다", "이번 기회가 좋은 계기가 되도록")을 덧붙이지 않았는가?
- [ ] 짧은 확인 회신(받은 것 확인 + 처리 결과)이면 감사 도입문·이모지 없이 결과부터 2~3줄로 끝냈는가? 예: "총 24명 11월 {대상} 명단 확인하였습니다."
- [ ] 소리 내어 읽었을 때 실무자가 바로 써서 보낸 길이인가? (본문 200~450자 안팎)
